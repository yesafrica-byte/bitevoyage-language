[5] 설치 및 SEO 제한
 - Blogger 콘텐츠에서 웹페이지 JS만으로 기기 홈 화면 아이콘을 직접 생성할 수 없습니다.
 - 모바일: Chrome/Safari/삼성 인터넷의 '홈 화면에 추가' 메뉴에서 진행하세요.
 - PC: Chrome/Edge의 '바로가기 만들기' 또는 동봉 .url / .webloc 파일 사용.
 - 홈 화면 바로가기는 네이티브 앱이나 완전한 PWA가 아닙니다.
 - 사용자 아이콘은 Blogger 사이트 favicon에 따라 달라지므로 Blogger 설정에서 favicon 교체를 권장합니다.
 - 웹 공유 버튼 자체가 검색 순위를 보장하지 않습니다. Blogger 게시물 제목/설명/검색설정 등은 별도 최적화.
 - 원문 및 음성 데이터는 이전 버전과 동일하며 중국어 병음·일본어 로마자 일부 자동 표기는 검수 대상입니다.
 - 자동 생성된 학습용 단어 경계는 문법적으로 완벽하지 않을 수 있습니다.
 - 광고 코드: 기존 ca-pub-9524179834302691 / slot 1443087299 유지. 게시 후 실제 로딩은 광고 서비스 정책·환경에 좌우.
