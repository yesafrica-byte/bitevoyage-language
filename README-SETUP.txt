BiteVoyage Language Quest Premium V5.1 — GitHub Pages upload pack

Repository: https://github.com/yesafrica-byte/bitevoyage-language
Upload these three files to repository root:
- data.js (896 entries, original V5 content retained)
- engine.js (learning engine)
- index.html (standalone demo, optional but recommended)
Do NOT upload blogger-embed.html as the homepage: it is for Blogger HTML editor.

Enable GitHub Pages: Settings > Pages > Deploy from a branch > main / (root) > Save.
Expected preview URL (ONLY after Pages is enabled):
https://yesafrica-byte.github.io/bitevoyage-language/
Expected JS URLs (ONLY after Pages is enabled):
https://yesafrica-byte.github.io/bitevoyage-language/data.js
https://yesafrica-byte.github.io/bitevoyage-language/engine.js

Then open blogger-embed.html, copy entire HTML, replace the old article's V1-V4 code in Blogger HTML view, and publish.
Do not switch to Compose mode before publishing.
